# Installera ChatPretzel

1. Dra `ChatPretzel.app` till mappen Applications.
2. Öppna ChatPretzel från Applications.
3. Logga in på ChatGPT som vanligt.

ChatPretzel är ad-hoc-signerad och inte notariserad. Om macOS blockerar första starten kan du kontrollklicka på appen, välja **Öppna** och bekräfta.

ChatPretzel är ett fristående, inofficiellt projekt och är inte anslutet till eller godkänt av OpenAI.
